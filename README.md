One original funny line — an entry for make.fun's "The One-Line Laugh" bounty ($5 in USDC).

## The laugh

> I bought noise-cancelling headphones to focus, and now I can hear my own thoughts procrastinating.

98 characters, one line. The full line also lives in `laugh.txt`.

## Run it

```sh
python3 main.py
```

`main.py` reads the line from `laugh.txt` and writes it byte-identically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
